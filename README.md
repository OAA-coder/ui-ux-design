# «Между строк» — книжный интернет-магазин

Интерактивный веб-сервис для поиска, подбора и покупки книг с каталогом, карточками изданий и личным кабинетом читателя. Проект интегрирован с открытой библиографической базой **Open Library**.

## ✨ Основной функционал

### 1. Каталог и поиск («Книжная полка без границ»)
- **Поиск:** поиск изданий по названию, автору или коду ISBN через API Open Library.
- **Фильтрация:** отбор книг по жанрам (классика, фантастика, фэнтези, современная проза, нон-фикшн), языку издания (русский / английский) и годам выпуска.
- **Сортировка:** сортировка по популярности, новизне и цене.
- **Избранное:** быстрое добавление книг в список «Отложено на потом» прямо из карточки в каталоге.

### 2. Карточка книги
- Полная библиографическая информация: автор, жанры, формат обложки, количество страниц, год первой публикации, издательство и ISBN.
- Краткая аннотация и описание книги.
- Добавление товара в корзину и в избранное.
- Блок персональных рекомендаций («Продолжите знакомство с классикой»).

### 3. Личный кабинет («Читательский уголок»)
- Управление профилем: ФИО, email, город, язык предпочитаемых изданий.
- Навигация по разделам: «Личные данные», «Моя полка», «Мои заказы», «Настройки».
- Виджет быстрого доступа к отложенным книгам («Отложено на потом»).
- Настройка уведомлений и подписок («Книжная почта»: персональные рекомендации, новости и скидки).
